# Перекидные часы для iPad 2 (iOS 9.3.5, Safari)

Белые цифры на чёрном, листаются как механические перекидные часы.
Страница собрана **в одном файле `index.html`** (CSS и JS внутри) с расчётом на
старый WebKit: только ES5, только `-webkit-`-префиксы, без CSS-переменных,
grid/flex, calc() и прочих вещей, которых нет в iOS 9.

## Состав папки

| Файл                 | Зачем                                                        |
|----------------------|--------------------------------------------------------------|
| `index.html`         | сама страница часов (всё внутри, внешних зависимостей нет)    |
| `apple-touch-icon.png` | иконка для ярлыка «На экран Домой»                          |
| `serve.py`           | простой HTTP-сервер без кэша для HTML + печать адресов сети  |
| `make_icon.py`       | генератор иконки (чистый Python, без PIL) — на сервере не нужен |

## Быстрый старт (Python)

```bash
# скопируйте папку flipclock на сервер, затем:
cd flipclock
python3 serve.py 8000          # порт можно поменять: python3 serve.py 8080
```

Сервер слушает `0.0.0.0`, печатает адрес в локальной сети и отдаёт любой
неизвестный путь как `index.html` (часы откроются по любому URL сайта).
HTML отдаётся с `Cache-Control: no-store` — после правок достаточно обновить
страницу, старый кэш не прилипнет.

В фоне (переживёт закрытие терминала):

```bash
nohup python3 serve.py 8000 >/var/log/flipclock.log 2>&1 &
```

или systemd-юнит `/etc/systemd/system/flipclock.service`:

```ini
[Unit]
Description=Flip clock for iPad
After=network.target

[Service]
WorkingDirectory=/opt/flipclock
ExecStart=/usr/bin/python3 serve.py 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

## Если у вас nginx / apache

Файлы статичны, подойдёт любой сервер. Достаточно положить `index.html`
и `apple-touch-icon.png` в корень сайта (или в подпапку). Для nginx:

```nginx
location /clock/ {
    alias /opt/flipclock/;
    index index.html;
    add_header Cache-Control "no-store";
}
```

## Настройка iPad

1. В Safari откройте `http://АДРЕС-СЕРВЕРА:8000/`.
2. **Коснитесь экрана один раз** — включится «не засыпать» (тихий циклический
   звук, громкость 1%, его не слышно) и станут доступны настройки.
3. Нажмите «Поделиться» (□) → **«На экран Домой»**. Ярлык запустит часы
   без адресной строки и панелей Safari — на весь экран.
4. Настройки вызываются **одним тапом** по экрану (панель сама прячется через 6 с):
   - **«Во весь экран»** — программный fullscreen прямо в Safari;
   - **«Секунды»** — цикл: нет → перекидные карточки → текст `:СС`;
   - **«Дата»** — показать/скрыть строку даты;
   - **«Ярче»** — чисто-белый на чисто-чёрном вместо мягкого режима.
   Все настройки запоминаются на устройстве (localStorage).

Время берётся из часов самого iPad.

## Где крутить вкусности

- Скорость перекидывания: в CSS `0.30s` у `.anim-leaf-a` / `.anim-leaf-b`
  (+ задержка `0.30s` у leaf-b) и константа `FLIP_MS = 600` в JS (страховка).
- Масштаб циферблата: коэффициенты в функции `layout()`
  (`0.30 * ширина`, `0.50 * высота` экрана).
- Цвета: правила `body.pure` (яркий режим) и обычные `#0b0b0b / #e8e8e8`.
- Шрифт цифр: `font-family` в правиле `.digit` (сейчас Helvetica Neue —
  системный, грузить извне нечего).
